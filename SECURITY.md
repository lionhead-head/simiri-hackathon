# Security Policy

This repository accepts synthetic demonstration data only.

Never submit real customer or merchant data, recordings, images, wallet details,
private URLs, access codes, API keys, passwords, tokens, signing material, provider
responses, production logs, or private Simiri source.

If you discover sensitive information, do not open a public issue or copy the
information elsewhere. Contact the repository owner privately so the repository
can be locked and reviewed before any publication continues.
